BIROOT FREE PWA STARTER

Files:
- index.html: responsive shop catalogue, search, categories, cart and order-request export
- manifest.json: installable app metadata
- sw.js: basic offline caching

IMPORTANT LIMITATIONS:
- This is a front-end starter/demo, not yet a live commercial ordering system.
- Orders are not automatically delivered to the shop and are not stored in a server database.
- No payment gateway, seller accounts, inventory sync, admin login, delivery tracking, or legal/compliance workflow is included yet.
- Product prices marked “Ask price” are placeholders, not confirmed prices.
- To use the PWA install features, host over HTTPS (for example, GitHub Pages).

FREE DEPLOYMENT OUTLINE:
1. Create/sign in to a GitHub account.
2. Create a public repository named biroot-shop.
3. Upload index.html, manifest.json, and sw.js to the repository root.
4. In repository Settings > Pages, enable deployment from the main branch/root.
5. Open the generated HTTPS Pages URL on your phone. On Android use browser menu > Install app/Add to Home screen. On iPhone use Safari > Share > Add to Home Screen.

Before accepting real orders, add the shop's WhatsApp number, confirm all prices/weights/stock/delivery fees, and set up a secure backend or order service. Never collect sensitive payment information in this demo.
